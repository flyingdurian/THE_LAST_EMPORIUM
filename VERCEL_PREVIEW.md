# Vercel browser preview

This preview is an export of the repository's current Godot 4.3 project state.
It is not a claim that the newer Moonlighter-style fantasy shop-floor art direction
has been implemented. The current project launch scene remains `ui/Japan.tscn`.

Vercel builds the Web export using `scripts/vercel_build.sh` and serves
`build/web` as a static site. The script downloads the matching Godot 4.3
Linux export binary and export templates during the build.
