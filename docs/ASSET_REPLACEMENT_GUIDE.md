# Gate D2 project-level replacement
All artwork is temporary benchmark art, not approved final production. Edit data/d1_assets.json to change imported res:// texture paths or replace the same files. Godot reimports; no scene edits. Floor is a full empty room plate; counter_room.jpg is architecture only, counter_surface.jpg masks lower customer body. Portraits neutral/pleased/offended share 380×496 transparent canvas and anchor. vessa_floor.png is the same costume/identity from the back. Shelf and rack are 300×164 transparent PNGs. Items have independent display_sizes (world width/height and offsets), counter stage path overrides (sword horizontal), stage_rects and stage_shadows (base coordinates on physical tabletop), and logical slot compatibility. Counter sockets are authored x,y,scale projections, not free placement. UI and registry use 1280×720 base. Fixed architectural decor is not merchandise. Add cue files audio/arrival.ogg, sale.ogg, click.ogg, text.ogg, tension.ogg to replace synthesized defaults. AudioManager retains mute/volume. No runtime overrides. See art/PROVENANCE.md for original generated/cropped temporary assets.
