# D1 project asset replacement
All D1 assets are temporary and not approved final artwork. The full empty-room floor plate is generated temporary benchmark art; DragonStone and customer art are retained from Gate C. See art/PROVENANCE.md. D1 wood, shelf, rack, sword and shield are original source SVG placeholders, not externally sourced.

Edit data/d1_assets.json to point to imported res:// PNG assets (or replace the existing PNG at the same path). Godot imports on project open; no scene or gameplay code edit needed. Keep transparent backgrounds for fixture and merchandise art. The floor is a full 1280×720 empty-room plate, drawn in the 1280×622 play area. No interactive furniture is baked in; furniture canvas 260×130; merchandise uses aspect-fit display and 470×282 large counter stage. The socket coordinates are authored UI positions at 1280×720; change only deliberately. Slots 0–1 belong to shelf, 2–3 to rack. Changing artwork does not change ownership or slot capacity. Export must include JSON and referenced textures. Runtime overrides deferred.
