# Gate E — five-day playtest (provisional development scenario)
Launch the Windows export (extract EXE and PCK together) or Godot 4.3 project, F5. Main is ui/Week.tscn. Save/load in Menu; Debug reset starts a new Week without modifying D2 saves. No API/network or text interpretation. Use Respond choices and price spinner.
- Day 1: Stockroom → appraise DragonStone → Restock. Shop Floor → Merchant journal → optional Iona expedition (90g, two days). Open shop, serve Vessa. Set counteroffer spinner to 650; Show appraisal then Acknowledge/reassure. Confirm sale only when pending. Next visitor Bram sells Silver Locket for 65g; inspect if desired, review offer, confirm buy. Close and read the report.
- Day 2: Journal training (50g), storage expansion (75g), sign (60g) optional. Marla wants Emberroot; display it if missing. Offer 60g or review her offer. Vessa returns and remembers fair or hostile conduct. End conversation, close.
- Day 3: If sent Day 1, expedition returns with loot and possible injury; see journal/stockroom. Installment 250g; pay in morning or keep the cash and receive a recoverable warning at closing. Bram wants Knight's Blade (display rack). Ask about the quarry if the evidence is known, then offer item + gold trade. Review 90g plus Warding Tome and confirm; ledger preserves terms. Caldus wants shield, resists intimidation. Close.
- Day 4: Nyx offers Star Compass for 85g. Buy or decline. Marla returns with a request; reassure or dismiss. Sign upgrade creates one additional Tovin visit; no daily quota visible. If you want the compass for Day 5, keep it stored.
- Day 5: Display compass, serve Tovin, then Bram's return conversation. Pay remaining installment if desired. Demand expires; close final ledger. No hard game over for missed debt.
Notes: visits are authored, not a procedural town simulation. Display matters: missing requested goods turns the visit into a social encounter. Fixed test route uses 650g Vessa only under specified appraisal/rapport conditions. Other valid prices vary. New art and balance are provisional. The Windows export is built in CI; Linux Godot automated runtime and screenshots are evidence, not a manual Windows playtest.
